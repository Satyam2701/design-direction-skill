# design-direction v1.1 Quick Wins Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship v1.1 of the design-direction skill: smart intake with quick mode, a palette with dark mode and semantic roles, WCAG contrast checks, and a tighter description.

**Architecture:** All behavior lives in the prompt `skills/design-direction/SKILL.md`. Tests in `test/install.test.js` lock in the structural guarantees: description length and the presence of the required sections. No runtime code changes.

**Tech Stack:** Markdown prompt, Node ≥16 built-in `assert` tests (`npm test`).

## Global Constraints

- No new dependencies; tests use only Node built-ins.
- The parsed description must be ≤ 400 characters.
- WCAG 2.2 AA: 4.5:1 normal text; 3:1 large text (≥24px, or ≥18.66px bold) and UI components.
- Commits carry no co-author or attribution trailers.
- Version 1.1.0. Do not push a release tag in this plan.
