# design-direction v1.2 Style Tile Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Generate a style tile and token exports from a single tokens.json, as specified in
`docs/superpowers/specs/2026-10-03-v1.2-style-tile-design.md`.

**Architecture:** A dependency-free `skills/design-direction/scripts/build.js` validates the tokens,
checks contrast, and renders the outputs. SKILL.md Phase 2 drives it. The installer copies the whole
skill directory.

**Tech Stack:** Node ≥16 built-ins only (`fs`, `path`, `assert`, `child_process`).

## Global Constraints

- No dependencies. Node ≥16.
- Exit codes: 0 = ok, 1 = contrast failure (outputs still written), 2 = invalid tokens (nothing written).
- The required color roles, typography styles and contrast pairs are exactly as listed in the spec.
- No attribution trailers in commits.
