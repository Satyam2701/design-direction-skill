# design-direction v1.1 — Quick Wins

**Date:** 2026-10-03
**Status:** Approved
**Scope:** `skills/design-direction/SKILL.md`, `test/install.test.js`, `README.md`, version bump to 1.1.0

## Goals

Fix the four most visible weaknesses of v1.0 with edits to the skill prompt only. No new files in the
package, no new dependencies.

## 1. Smart intake (Phase 1)

- Before asking anything, extract answers to the five intake questions (audience, product, anti-brief,
  references, one word) from the user's opening message and any earlier conversation.
- Confirm what was inferred in one short line, then ask only the missing questions, one per message.
- If three or more answers are missing, first offer a choice: one at a time, or all at once. In
  all-at-once mode, present the missing questions as a single short numbered list.
- One-at-a-time remains the default.

## 2. WCAG contrast checks (Phase 2)

- The spec gains a **Contrast Check** table, covering both light and dark modes, for these pairs:
  - Neutral 900 on Background
  - Neutral 900 on Surface
  - Neutral 600 on Background
  - On Primary on Primary
  - Accent on Background (only if Accent is used as text)
- Targets (WCAG 2.2 AA): 4.5:1 normal text, 3:1 large text (≥24px, or ≥18.66px bold) and UI components.
- Any failing pair is fixed by adjusting lightness while keeping hue, then rechecked. The final table
  shows only passing values.
- If Claude can run code, it must compute the ratios with a script; it must never estimate them.
  If it cannot run code, it labels the ratios "approximate" and includes the WCAG relative-luminance
  formula so the user can verify.

## 3. Semantic colors + dark mode (Phase 2)

- The palette table becomes `Role | Light | Dark | Usage`.
- New roles: On Primary, Success, Warning, Error, Info.
- Dark values are derived from the same mood (not a simple inversion): surfaces are tinted rather than
  pure black, and saturation is reduced for large areas.

## 4. Tighter description

- Lead with the output (mood brief → spec → feature thinking), then the triggers.
- Add triggers: "style guide", "moodboard", "brand direction", "color palette".
- The parsed description must be ≤ 400 characters.

## Testing

Add the following to `test/install.test.js`:
- The parsed description is ≤ 400 characters.
- `SKILL.md` contains: the `Light | Dark` palette header, the Success/Warning/Error/Info/On Primary
  roles, a Contrast Check section, and the quick-mode intake instruction.
